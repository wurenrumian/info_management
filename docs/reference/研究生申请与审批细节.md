# 中国人民大学研究生学籍管理规定：申请与审批事项详细清单

本文系统整理《中国人民大学研究生学籍管理规定》中所有涉及学生申请、导师审核、学院审批、研究生院审核、学生处审批的具体事项，便于研究生查询和实际办理。

---

# 一、新生入学阶段

## （一）延期报到

### 适用情形

新生因特殊原因不能按学校规定时间报到。

### 办理规则

* 应在规定报到日期前提出申请。
* 须提交书面说明及相关证明材料。
* 请假期限不得超过14天。

### 审批流程

1. 研究生本人提出书面申请；
2. 所在学院审批；
3. 报学生处备案。

### 注意事项

* 未请假、请假未获批准或逾期未报到的，可能按放弃入学资格处理。

## （二）保留入学资格

### 适用情形

* 身心健康状况暂不适宜在校学习；
* 应征入伍；
* 国际学生暂未获得奖学金；
* 其他经学校认定的特殊情况。

### 保留期限

* 因参军：可保留至退役后2年；
* 其他原因：原则上保留1年。

### 审批流程

1. 本人提出书面申请并提交证明材料；
2. 博士研究生须先征得导师同意；
3. 所在学院审核同意；
4. 研究生院审核同意；
5. 报学生处审批。

### 特别说明

* 保留期间不具有学籍；
* 不缴纳学费；
* 不享受在校生待遇；
* 不安排住宿。

# 二、注册与日常管理

## （一）暂缓注册

### 适用情形

因特殊情况无法在注册期限内完成注册。

### 办理规则

* 须书面向学院说明情况；
* 暂缓期限不得超过14天。

### 审批流程

1. 学生提出申请；
2. 学院审核同意并出具书面意见；
3. 学生在开学后15天内到学生处补注册。

## （二）离校请假

### 适用情形

* 离开校区所在城市；
* 离校2日及以上；
* 涉及缺席教学活动。

### 审批流程

1. 学生按规定提出请假申请；
2. 班主任审批；
3. 学院领导审批。

# 三、学籍信息变更

## （一）内地学生信息变更

### 可申请事项

* 姓名
* 身份证号
* 性别
* 民族
* 籍贯

### 审批流程

1. 学生向学院提交书面申请；
2. 提供公安机关证明及相关材料；
3. 学院复查入学资格并审核；
4. 按事项分别审批：

   * 一般信息：学生处审批；
   * 身份证号涉及省份变更：学生处会同招生部门核查后审批；
   * 涉及出生日期变更：报教育部审批。

# 四、转导师、转研究方向、转专业、转学

### 审批流程

1. 学生提出申请；
2. 导师同意；
3. 学院同意；
4. 研究生院审批。

## （二）转专业

### 适用情形

* 原专业无法继续学习；
* 对其他专业具有明确研究专长。

### 审批流程

1. 学生提出申请；
2. 原导师、原学院同意；
3. 拟转入导师、拟转入学院同意；
4. 转入学院组织考核；
5. 转入学院报研究生院审批；
6. 学生处办理学籍变更。

### 注意事项

* 不得改变录取类别和学习形式。

## （三）转学（转出）

### 申请条件

仅限患病或特殊困难等正当理由。

### 办理时间

每年5月、11月受理。

### 审批流程

1. 学生本人提出申请；
2. 导师审核；
3. 学院审核；
4. 研究生院审核；
5. 学生处审核；
6. 专门会议审议；
7. 学校主管领导批准；
8. 校内公示；
9. 按北京市教委规定办理备案或审批。

# 五、休学与复学

## （一）休学

### 适用情形

* 身心健康问题；
* 创业；
* 因私出国90日以上；
* 因公出国且需中断学业；
* 应征入伍；
* 其他需中断学业情形。

### 审批流程

1. 学生提出申请并提交证明材料；
2. 导师审核；
3. 学院审核；
4. 学生处审批。

### 特殊情形

* 因病休学：需校医院诊断；
* 创业休学：需创业学院专家审核。

### 办理期限

4. 学生处审批。

### 特殊要求

# 六、毕业相关事项

## （一）提前毕业

### 申请条件

提前完成培养方案全部要求并符合毕业条件。

### 办理期限

预计毕业前三个月提出。

### 审批流程

1. 学生提出申请；
2. 导师同意；
3. 学院主管负责人批准；
4. 报研究生院审核。

fileciteturn3file0turn3file4

---

## （二）延长学习年限

### 申请条件

未按期完成培养方案或考核未通过。

### 办理规则

* 每次延长不超过1学年；
* 须于原预计毕业时间前三个月申请。

### 审批流程

1. 学生提出书面申请；
2. 导师同意；
3. 学院（系）批准；
4. 研究生院审批。

### 年限上限

* 硕士最长5年；
* 博士最长8年。

# 十、研究生管理的典型特点

相比本科生，研究生学籍管理有三个鲜明特点：

1. 导师参与度极高；
2. 研究生院是核心审批部门；
3. 涉及培养方案的事项审批更严格。

简单来说：

> 本科看学院，研究生看导师；
> 本科重课程，研究生重培养。
