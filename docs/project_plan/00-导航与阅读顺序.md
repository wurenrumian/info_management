# 00 导航与阅读顺序

## 文档目的

这套文档只保留“开发必须用到”的 6 份核心文件，按执行顺序阅读即可。

## 先读什么

1. `01-项目总方案.md`：先统一边界与技术路线
2. `03-API规范.md` + `03-openapi-phase1.yaml`：先冻结接口
3. `04-数据库设计-DDL.md`：冻结核心表结构
4. `02-阶段开发计划.md`：按阶段推进开发
5. `05-协作与验收.md`：按统一流程联调与交付

## 文件说明

1. `01-项目总方案.md`：项目目标、边界、角色权限、系统架构
2. `02-阶段开发计划.md`：Phase 1/2/3 的任务与产出
3. `03-API规范.md`：整体 API 规范 + Phase 1 详细 + Phase 2 文字草案
4. `03-openapi-phase1.yaml`：Phase 1 可导入 OpenAPI
5. `04-数据库设计-DDL.md`：Phase 1 核心 DDL 与索引建议
6. `05-协作与验收.md`：分支、PR、测试、里程碑、交付清单
